06. Presupuesto, herrajes y herrería
Fuentes consultadas: 06/11/2026. Solo se etiquetan como publicados los precios expresamente observados en páginas de proveedor. No se realizan consultas en tiempo real ni scraping desde este HTML. Los precios manuales son presupuestos de usuario, no cotizaciones verificadas.
Herrajes automáticos sugeridos
Las cantidades se calculan por configuración; el largo real de guía, la capacidad de carga y la compatibilidad del espesor deben verificarse antes de fabricar. En SO Class el proveedor publica precio por pieza: verificar si el SKU comprado incluye un par antes de cerrar presupuesto.
Herrería metálica opcional
El PTR se agrega exclusivamente como partida económica y no como diseño estructural automático; definir sección, calibre, uniones, placas, anclajes y cargas antes de fabricar.
